# 케어닥(Caredoc) B2B·기업회원 구조 분석

> 실측일: **2026-08-03** · 조사 방법: caredoc.kr / company.caredoc.kr / careops.caredoc.kr /
> mro.caredoc.kr / webview.caredoc.kr(약관) 직접 열람.
> 목적: 돌보다 `/business`(시설 운영자 입점) 설계의 비교 기준.

## 0. 한 장 요약

케어닥의 "기업회원"은 **하나의 가입 상품이 아니라, B2C 플랫폼 위에 얹은 B2B 사업 4개의 묶음**이다.

```
                    ┌─ B2C (caredoc.kr) ─────────────────────────┐
                    │  간병·가사돌봄·방문운동 매칭 + 시설찾기      │
                    │  = 트래픽·데이터·브랜드를 만드는 층          │
                    └───────────────┬────────────────────────────┘
                                    │ 여기서 생긴 자산을 B2B로 판다
   ┌────────────────┬───────────────┼────────────────┬───────────────┐
   │ ① 프랜차이즈     │ ② 케어옵스      │ ③ MRO 폐쇄몰    │ ④ 직영시설      │
   │ 가맹비·로열티     │ SaaS 구독      │ 공급 마진       │ 운영 수익       │
   │ company.caredoc │ careops.caredoc│ mro.caredoc    │ 너싱홈·케어홈    │
   └────────────────┴────────────────┴────────────────┴───────────────┘
```

- **caredoc.kr 헤더의 "기업회원" 버튼**은 별도 가입 페이지가 아니라 ②·③으로 가는 관문이다.
  로그인 벽 뒤에 있어 일반 계정으로는 안 들어가진다 — 심사형 B2B 계정이 따로 있다.
- 사용자가 준 주소(company.caredoc.kr/partnership)는 기업회원이 아니라 **① 프랜차이즈 가맹 모집** 페이지다.
- 규모(자사 공개 기준): 누적 거래액 3,700억+, 누적 돌봄 70만 건, 제휴 병원 170+,
  운영 지점 37+, 케어코디(간병인) 프로필 8만+. 2027 코스닥 상장 추진 보도(2026.4).

## 1. 사업별 상세

### ① 프랜차이즈 가맹 (company.caredoc.kr/partnership)

시설을 **차리려는 사람**(예비 창업자)에게 파는 상품. 페이지 구성이 교과서적이다:

| 순서 | 섹션 | 하는 일 |
|---|---|---|
| 1 | 시장 확신 | "노인 1,026만 명 · 장기요양 급여비 17.6조→40.9조" 숫자 폭격 |
| 2 | 비교표 ×2 | 외식·편의점 vs 시니어케어 / 경쟁사(A사·D사) vs 케어닥 |
| 3 | 본사 인프라 6종 | 운영 노하우·인력 매칭·제휴 병원·인허가 A등급·보험 연계·MRO |
| 4 | 사업모델 3종 탭 | 방문요양(소자본)·주야간보호(중규모)·요양원(규모형) + "이런 분께 추천" |
| 5 | 수익 구조 | "매출이 손님이 아니라 정부 수가에서 나온다" — 85% 공단 부담 강조 |
| 6 | 개원 5단계 | 상담→입지분석·계약→인허가 대행→인테리어·인력→개원 동행 |
| 7 | 신뢰 장치 | 전속모델(류승룡)·연혁·제휴사 로고·원장 후기 3건·FAQ |
| 8 | 상담 폼 | **항목 최소화**(모델·연락처) + 1영업일 내 연락 약속 + 창업설명회 |

특기사항:
- 예상 수익표를 **전부 "○○명 · ○,○○○만원"으로 가려놓고** "상담 시 산출" — 리드 수집 장치
- "특정 수익을 보장하지 않으며" 면책 문구를 표 바로 아래 배치 (가맹사업법 의식)
- 공실 상가 보유자용 "공간 활용 상담" 별도 트랙 — 부동산 보유자를 따로 낚는다

### ② 케어옵스 CareOps (careops.caredoc.kr) — 시설 운영 SaaS

시설을 **이미 운영하는 곳**(주로 실버타운·시니어하우징)에 파는 구독형 소프트웨어.

- **문제 정의 4종**: 입주관리(엑셀·종이) / 시설관리(전화·메신저로 흩어진 보수 요청) /
  건강관리(병원 데이터 단절) / 재무관리(월말 수작업 정산)
- **기능 범위**: 상담→계약→생활→건강→정산→퇴거 6영역. 경영 대시보드, 상담 유형별
  추이(마케팅 효율 측정), 입주자 건강 시계열(혈압·심박·혈당), 식단·영양, IoT·스마트워치
  연동, 출입·주차, 민원·하자, ERP 연동, AI 위험 예측
- **사용자 분리**: 운영자=웹 / 입주자·보호자=앱 / 현장 직원=태블릿 / 협력업체까지 계정 분리
- **패키지 3단**: 기본(필수 11종) → 프로페셔널(+선택 11종, ★추천) → 프리미엄(전체 25종)
- **가격 전부 비공개** — "도입 상담" 유도. 계약 6~8개월 전 구축 시작하는 엔터프라이즈 영업
- 보안 페이지 별도(암호화·RBAC·백업/이중화) — 시설장 결재용 자료

### ③ MRO 회원전용몰 (mro.caredoc.kr)

"시니어시설 맞춤형 최저가 온라인몰". **로그인 벽 뒤 폐쇄몰**로 식자재·소모품·기자재를
시설에 공급한다. 가맹점엔 "운영비 절감"으로 팔고, 케어닥은 공급 마진을 갖는다.
프랜차이즈(①)와 묶여 "본사 통합 공급으로 원가 절감" 논리를 완성한다.

### ④ 직영·가맹 시설 (너싱홈·케어홈·재가센터·데이케어)

케어닥이 직접 차린 요양원·실버타운. B2C 시설찾기의 "추천 시설" 최상단에 자사 시설
(케어닥 너싱홈 옥정·배곧 등)이 노출된다 — **플랫폼이 자기 시설의 광고판**이다.

### 보조 수익원 (홈에서 확인)

- 회원 혜택 "AD" 섹션: 여행·보청기·상조·추모공원 제휴 광고
- 케어인슈어런스: 보험사(삼성생명 제휴) 간병비 청구 연동
- 커뮤니티 구인 게시판: 시설 구인 공고가 자연 발생 (아직 상품화 흔적은 안 보임)

## 2. 약관에서 확인한 것 (webview.caredoc.kr/terms)

통합 이용약관(2026-05-04 시행)은 **B2C 매칭 중심**이다. 기업회원 조항은 이 문서에 없고,
B2B는 별도 계약(케어옵스 도입 계약·가맹 계약·폐쇄몰 회원 심사)으로 처리하는 구조로 보인다.

돌보다가 참고할 만한 조항 설계:

| 조항 | 내용 | 시사점 |
|---|---|---|
| 매칭 정의 | 공고 등록→지원→선택→결제수단 등록 4단계를 약관에 명문화 | 돌봄 흐름 상태 전이를 약관에도 맞출 것 |
| 무료/유료 경계 | "무료서비스 = 구인공고 등록·알림·방문요양센터 상담"으로 명시 | 무료 범위를 약관에 못박으면 과금 전환 때 분쟁이 준다 |
| 수수료 구조 | 이용요금 = 서비스 요금 + 서비스 수수료, 정산식 공개 | 수수료를 숨기지 않고 계산식으로 공개 |
| 취소 수수료 | 72h/48h/24h 구간표 (1만/2만/3만, 시작 후 5만) | 구간표 방식이 분쟁을 줄인다 |
| 매칭 비보장 | "회사는 그 어떠한 경우에도 매칭 결과를 보장하지 않는다" | 결과 비보장 명시 |
| 보험 | 회사=계약자, 케어코디=피보험자 단체보험, 보험료 선차감 정산 | 돌보다 매니저 보험 도입 시 참고 구조 |
| 미수 처리 | 2영업일 중단 → 7영업일 채권 회수(신용정보사 위탁) | B2B 구독 미납 처리에도 같은 단계 설계 필요 |

### 시설 상세 페이지 (돌보다와 직접 비교되는 부분)

일반 시설(복음실버타운) 상세를 열어보면 구성이 돌보다와 거의 같다 — 공단 평가등급·영역별
점수·입소 현황(정원/현원/대기)·비급여·인력·시설 현황·프로그램 목록·교통편. 전부 공공데이터.

- **"시설 관계자이신가요?" 같은 클레임(입점) 버튼이 없다** — 일반 시설이 자기 페이지를
  가져갈 공식 통로가 화면에 없음
- 시설 상세의 "이 시설 이야기" = 사용자 리뷰 (비어 있는 곳이 대부분)
- 하단 고정 CTA는 "전화 문의하기" — 상담 리드를 플랫폼이 잡지 않고 전화로 흘려보낸다
- 추천 시설 자리에 자사 직영(너싱홈)이 반복 노출

## 3. 케어닥 vs 돌보다 — 전략 비교

| 축 | 케어닥 | 돌보다 (현재) |
|---|---|---|
| 본업 | 간병인 **매칭 거래** (수수료) | 시설 **정보 비교** (안심지수) |
| B2B 대상 | 창업자(가맹)·실버타운(SaaS) | 기존 시설 운영자 (노출·페이지 관리) |
| 시설과의 관계 | 직영·가맹으로 **직접 운영** | 운영하지 않음, 정보와 연결만 |
| 가격 공개 | 전부 비공개 (상담 유도) | **전부 공개 + 부가세 별도 명시** |
| 데이터 | 거래 데이터 (특허 매칭·가격예측) | 공공데이터 + 안심지수 계산식 공개 |
| 시설 페이지 클레임 | 공식 통로 없음 | `/business` 무료 인증 → 콘솔 |
| 상담 리드 | 전화로 유출 | 플랫폼이 접수·전달 (기록 남음) |
| 이해충돌 | 자사 시설을 추천 자리에 노출 | 광고를 '광고'로 분리 표시 |

### 돌보다가 가져갈 것

1. **가입단 리드 폼 최소화 + "1영업일 내 연락"** — 이미 반영됨
2. **취소·미납의 구간표 방식** — 구독 해지·미납 정책을 만들 때 표로 명문화
3. **무료/유료 경계의 약관 명문화** — 지금 화면에만 있는 무료 범위를 이용약관에도
4. **공간 보유자 트랙** — 나중에 시설 창업 수요가 보이면 별도 랜딩으로

### 돌보다가 다르게 갈 것 (차별점)

1. **가격 공개** — 케어닥 B2B는 전부 "상담 문의". 소규모 요양원 사무국장은 전화해야
   가격을 아는 것 자체가 진입 장벽이다. 돌보다는 요금표를 공개한다
2. **시설 페이지 클레임 통로** — 케어닥에 없는 공식 입점 통로가 돌보다의 첫 상품
3. **광고와 정보의 분리 표시** — 케어닥은 자사 시설이 추천 자리에 노출되는 이해충돌
   구조. 돌보다는 스폰서를 '광고' 라벨로 분리 — 이게 신뢰 포지션
4. **상담 리드를 플랫폼에 남기기** — 전화 유출 대신 접수·전달·기록. 시설에겐
   "몇 건 왔는지"가 곧 유료 전환의 근거가 된다

## 4. 케어닥 성장 경로가 보여주는 돌보다의 다음 단계 후보

케어닥 순서: 매칭(B2C) → 직영 시설 → 프랜차이즈 → SaaS·MRO. 돌보다에 대입하면:

| 단계 | 케어닥 대응물 | 돌보다 버전 | 전제 |
|---|---|---|---|
| 지금 | 시설찾기 | 무료 인증 + 비즈니스 플러스 + 지역 스폰서 | 배포 + 첫 인증 시설 |
| 다음 | 상담 전화 유출 | 상담 리드 리포트 (시설 콘솔 통계) | 인증 시설 수십 곳 |
| 그다음 | MRO | 시설용 공동구매/제휴 혜택 | 유료 시설 기반 |
| 장기 | 케어옵스 | 소규모 시설용 경량 운영 도구 | 콘솔 사용 데이터 |

케어옵스가 실버타운(대형)을 노리는 것과 달리, 국내 시설의 대다수는 **방문요양센터
(15,677곳)·소규모 요양원**이다. 이들에게 엔터프라이즈 SaaS는 과하고, "우리 시설 페이지
관리 + 상담 접수 + 간단 통계"가 맞는 크기다 — 돌보다 콘솔이 정확히 그 자리다.
