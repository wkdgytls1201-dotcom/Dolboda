## 한 문장 소개

**돌보다는 정보 비대칭으로 발생하는 돌봄 공백을 해결하고, 보호자가 신뢰할 수 있는 요양시설과 돌봄 서비스를 투명하게 비교·선택할 수 있도록 돕는 데이터 기반 에이지테크(AgeTech) 플랫폼입니다.**

## 1. 돌보다는

돌보다는 고령화 시대의 돌봄 정보 격차를 해소하는 시니어 케어 플랫폼입니다.

대한민국은 이미 초고령사회에 들어섰지만, 가족이 부모님의 돌봄을 준비하는 과정은 여전히 막막합니다. 어떤 요양시설이 좋은지, 비용은 적절한지, 실제 돌봄 환경은 어떤지 확인할 수 있는 정보는 부족하고 복잡하게 흩어져 있습니다. 그리고 대부분, 돌봄은 준비할 겨를도 없이 갑자기 시작됩니다.

돌보다는 이 돌봄 시장의 정보 비대칭을 해소하고 보호자의 합리적인 의사결정을 돕기 위해 만들어졌습니다.

정보 부족으로 좋은 돌봄의 기회를 놓치는 사람이 없도록,
보호자는 더 안심하고 선택할 수 있도록,
돌봄 제공자는 더 투명하게 신뢰받을 수 있도록.

**돌보다는 기술로 더 나은 노후와 돌봄의 기준을 만들어갑니다.**

### 비전
누구나 필요한 돌봄 정보를 투명하게 확인하고, 자신과 가족에게 가장 적합한 돌봄을 선택할 수 있는 사회를 만듭니다.

### 미션
돌봄 시장에 흩어진 정보를 연결하고 표준화하여 보호자와 시니어가 더 나은 돌봄을 선택할 수 있도록 돕습니다.

## 2. 지금까지 만든 것 (전부 서비스 중)

돌보다는 계획서 위의 회사가 아닙니다. 아래 기능은 **모두 www.dolboda.kr에서 실제로 동작하고 있습니다.**

### 2-1. 전국 요양시설 데이터 인프라

| 항목 | 규모 |
|---|---|
| 등록 시설 | **28,834곳** (전국 요양병원·요양원·주야간보호·방문요양) |
| 데이터 출처 | 국민건강보험공단·건강보험심사평가원 공공데이터 |
| 데이터 갱신 | **매일 새벽 자동 수집** — 정원·현원·대기·평가등급 변경분을 매일 반영 |
| 시계열 축적 | 시설별 일일 스냅샷 **27,000행+** — 빈자리 발생·등급 변동을 매일 감지 |
| 위치 정보 | 21,575곳 지오코딩 완료(95.6%) — "내 주변 시설" 거리 기반 검색 |

흩어진 공공데이터를 한곳에 모으는 데서 그치지 않고, **매일 갱신되는 살아있는 데이터베이스**로 운영합니다. 오늘 자리가 난 시설, 등급이 바뀐 시설을 데이터가 먼저 압니다.

### 2-2. 돌보다 AI 안심지수 — 보호자를 위한 독자 지표

평가등급 하나만 보지 않습니다. 인력 배치, 현원, 운영 정보, 행정처분 이력까지 공공데이터의 여러 신호를 가중 합산해 **시설마다 안심지수를 산출**합니다.

- 계산 방식을 **전부 공개**합니다 — 블랙박스 점수가 아닙니다
- 없는 데이터는 지어내지 않습니다 — 확보된 데이터가 절반 미만이면 점수를 내지 않고 "산출 보류"로 밝힙니다
- 광고비로 순위가 바뀌지 않습니다 — 광고는 분리된 자리에 '광고'로 표시합니다

### 2-3. 근무환경 지수 — 업계에서 돌보다만 하는 것

같은 공공데이터를 **반대편 시선으로 다시 읽었습니다.** 보호자에게 "모시기 좋은 시설"을 알려주는 데이터는, 돌봄 종사자에게 "일하기 좋은 시설"도 알려줄 수 있습니다.

- 업무 강도(요양보호사 1인당 담당 인원), 근속 안정성, **초기 이직률(6개월 내 퇴사 비율)**, 의료 지원, 기관 신뢰를 종합
- 전국 **11,400곳+** 입소형 시설에 산출 (커버리지 98%)
- 구간 기준은 임의값이 아니라 **실제 분포의 사분위수** — 시설 유형별 법정 배치기준까지 반영한 통계적 설계
- 요양보호사·간병인이 채용 공고 없이도 매주 들어와 볼 이유를 만듭니다

**경쟁사는 공공데이터를 종사자 관점으로 가공하지 않습니다.** 이것이 돌보다가 공급자(돌봄 인력)를 모으는 방식입니다.

### 2-4. 돌봄 인력 매칭 — 돌보다 매니저

시설 입소만이 답이 아닌 가족을 위해, 검증된 돌봄 인력(돌보다 매니저)과 보호자를 직접 연결합니다.

- 병원 간병·가사 돌봄·재가 돌봄 3유형, 4단계 요청 마법사
- 매니저 지원 → 보호자 선택 → 매칭 확정의 전 과정이 플랫폼 안에서
- **전자 돌봄 합의서**: 양측 전자서명, 서명 시점 내용 봉인(SHA-256 위변조 검증), 완성 시 양측에 사본 자동 발송
- 하나의 계정으로 보호자와 매니저 역할을 전환하는 통합 마이페이지

### 2-5. 장기요양 제도 내비게이션

제도를 모르는 보호자를 제도 안으로 안내합니다.

- **1분 등급 예상 테스트** — 공단 인정조사 항목 기반 자가진단
- **복지용구 혜택 안내** — 연 160만원 한도를 몰라서 못 쓰는 가족을 위한 품목별 상세 가이드(18개 품목), 대상자별 본인부담금 시뮬레이션, 전국 **1,600곳+ 복지용구 사업소** 찾기, 상담 신청
- 요양인정번호 등록·관리, 월 실부담 비용 시뮬레이터, 요양 가이드 콘텐츠 10편

### 2-6. 시설 파트너 채널 (B2B)

- 시설 입점 신청 → 서류 검증 → 시설 전용 콘솔 제공
- 시설이 직접 소개글·사진·소식을 발행 (공공데이터와 분리 표시 — 지표 신뢰성 보호)
- 페이지 조회수·상담 신청 통계, 월간 성과 보고서
- 지역 스폰서·배너 광고 (시군구당 수량 제한, '광고' 라벨 분리 표시)
- 상담 신청은 시설로 자동 전달 — 리드 파이프라인 구축 완료

### 2-7. 검색 인프라 (SEO/GEO)

- 지역×유형 조합 **1,100개+ 페이지** 자동 생성 (/region/경남/김해시/요양원 …)
- 전국 유형 허브(/요양원 등 한글 URL), 구조화 데이터(JSON-LD), AI 검색엔진 대응
- 구글 서치콘솔·네이버 서치어드바이저 등록 완료

## 3. 해결하고자 하는 문제

고령화가 가속화되면서 요양시설과 돌봄 서비스 수요는 증가하고 있지만, 보호자는 다음과 같은 어려움을 겪습니다.

1. 요양시설 정보가 여러 기관과 사이트에 분산되어 있습니다.
2. 시설별 비용과 서비스의 객관적인 비교가 어렵습니다.
3. 온라인 정보와 실제 돌봄 환경 사이에 차이가 존재합니다.
4. 갑작스럽게 돌봄이 필요해졌을 때 신뢰할 수 있는 정보를 찾기 어렵습니다.
5. 시설 입소 전후의 돌봄 과정이 서로 단절되어 있습니다.

돌보다는 **시설 검색과 비교(구현 완료) → 돌봄 인력 연결(구현 완료) → 사후 관리(확장 중)**로 이어지는 통합 돌봄 경험을 만들고 있습니다.

## 4. 돌보다가 일하는 방식 — 신뢰의 원칙

에이지테크는 결국 신뢰 산업입니다. 돌보다는 처음부터 세 가지 원칙을 코드에 박아두었습니다.

**공공데이터를 왜곡하지 않습니다.**
공단·심평원 자료를 임의로 바꾸지 않고 정제·표준화해 보여줍니다. 없는 값은 비워두고 "아직 공개되지 않았어요"라고 밝힙니다.

**이상한 값은 숫자로 보여주지 않습니다.**
원본에 '1일 1원' 같은 값이 섞여 있으면 그대로 노출하지 않고 '시설 문의 필요'로 표시합니다. 잘못된 숫자가 가족의 결정을 좌우하면 안 되기 때문입니다.

**광고와 정보를 구분해 보여줍니다.**
일반 목록의 순서는 거리·평가등급·안심지수로 매겨지고, 시설이 구매하는 스폰서 노출은 분리된 자리에 '광고'로 표시합니다.

개인정보도 같은 태도로 다룹니다 — 어르신의 이름·주민번호는 아예 받지 않고, 건강 상태는 구간값만 수집하며, 수집 항목이 늘 때마다 개인정보처리방침에 즉시 반영합니다.

## 6. 사업계획서용 요약

돌보다는 고령화로 증가하는 돌봄 수요와 공급자 중심으로 형성된 기존 시장의 정보 비대칭 문제를 해결하는 **데이터 기반 에이지테크 플랫폼**입니다.

국민건강보험공단·건강보험심사평가원의 공공데이터를 수집·정제·표준화하여 전국 28,000여 요양시설의 비용·인력·평가·서비스를 객관적으로 비교할 수 있는 환경을 구축했으며, 매일 자동 갱신되는 시계열 데이터 파이프라인 위에서 자체 지표(AI 안심지수·근무환경 지수)를 산출합니다. 시설 검색을 넘어 돌봄 인력 매칭과 전자 합의서, 장기요양 제도 안내, 시설 파트너 채널까지 **돌봄 여정의 전 단계가 이미 하나의 플랫폼에서 동작하고 있습니다.**

돌보다는 단순한 시설 정보 제공을 넘어, 돌봄이 필요한 시점에 가장 적합한 사람과 시설, 서비스를 연결하는 **대한민국의 시니어 케어 인프라**를 지향합니다.
